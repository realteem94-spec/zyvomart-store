ZyvoMart - Premium E-commerce Store

PROJECT
ZyvoMart is an online shopping store with free delivery
and Cash on Delivery (COD).

TECHNOLOGY
- HTML, CSS and JavaScript
- Supabase Authentication
- Supabase PostgreSQL Database
- Netlify Hosting

PLANNED FEATURES
- Customer registration and login
- Product categories and search
- Shopping cart
- Secure admin-only product management
- Purchase cost hidden from customers
- Stock and inventory management
- Customer delivery address
- Cash on Delivery orders
- Free delivery

SECURITY
- Never publish Supabase secret or service-role keys.
- Enable Row Level Security (RLS).
- Admin permissions must be verified securely.
- Order prices and stock must be validated on the server.

IMPORTANT
This project is under development.
Features are not considered operational until they
are implemented and tested.

ONLINE PAYMENTS
Online payments are not configured yet.
