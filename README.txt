ZYVOMART — PREMIUM FRONTEND STARTER
This is a new standalone static storefront branded ZyvoMart with a premium wine-red/orange/ivory design, responsive layout, search, category filters, demo products, cart quantity controls, product sharing, and a demo checkout/admin preview.

IMPORTANT LIMITATIONS:
- This is frontend/demo only. It does not connect to Supabase.
- Orders are NOT saved to a database; checkout only validates fields locally.
- Admin preview is NOT secure authentication. Demo products are stored in this browser only.
- Online payment is NOT enabled.
- Before launch, connect Supabase using a publishable key, implement Row Level Security policies, use a trusted server/edge function for order creation, secure admin authentication, stock/order validation, and verified payment webhooks.
- Never place Supabase service_role or payment secret keys in browser code.
- Deploy the contents as a new project; keep the old Deal Bazar repository/site untouched until the new site is verified.
